### 两个模式怎么共存

- 招式、被动、法器、境界、草丛、归宗这些**机制只有一份代码**。

- 十二人的基础数值和招式数值也是共用的；三路如果需要偏移，用"三路修正表"叠在上面（例如某人三路里气血 ×1.05），不去改共用的那份。这样一路的平衡不会被三路的调整带偏。

## 1. 地图

### 1.1 形状

- 方形地图，边长约 150。现在的一路地图是 160 × 96。
- 霜方山门在左下角，烬方在右上角。镜头方向不变（朝北），你永远是霜方，不需要镜像。
- 中路走对角线，长度与现在的一路相当（阵眼到阵眼约 128）。上下两路是折线，各约 180。
- 河道沿另一条对角线，从左上到右下，与中路在地图中心交叉。

### 1.2 建筑

- 每路每方三座灵塔（外塔、内塔、高地塔），共九座，守一座阵眼。
- 沿用现在的规则：前一座倒了后一座才能打；没有弟子护送时修士拆塔伤害大减。
- 任意一路的高地塔倒了，阵眼就可以被攻击。

### 1.3 野区

四块野区，每方两块。每块两到三个营地：

| 营地 | 数量（每方） | 给什么 |
|---|---|---|
| 血傀（现有） | 3–4 | 灵石和修为 |
| 灵力增益营 | 1 | 一段时间内灵力回复和调息加快，给中路或打野 |
| 灼烧增益营 | 1 | 普攻附带灼烧和减速，给打野或射手 |

河道上两个中立目标，一边一个，谁打掉归谁：

| 目标 | 位置 | 效果 | 对应 |
|---|---|---|---|
| 血海残魂（现有） | 上河道 | 全队伤害提升 | 偏团战 |
| 新目标，名字待定 | 下河道 | 下一波三路弟子强化，推塔更快 | 偏推进，是优势方的收尾手段 |

目标放在河道中线上，双方距离相等。Infinite Crisis 的三路地图也是把团队目标放在中央，理由相同。

### 1.4 草丛

沿用现有规则。位置：每路中段两侧、河道入口、野区通往线上的路口、两个中立目标旁。

### 1.5 寻路（新需求）

现在没有寻路：单位直线走，碰到树石就绕。一路够用，三路不够，因为野区和线之间需要有"墙"和"口"，抓人才有路线可言。

建议：

- 用几条**不可通过的山脊**（胶囊形障碍）把线和野区隔开，留出固定的入口。
- 铺一张**路点图**，约 60–80 个节点（线上、野区通道、河道、入口），节点间直线可达。
- 远距离移动在路点图上跑一次 A*，近距离仍用现在的直线 + 避障。

不做导航网格，成本高且这个规模用不上。

## 2. AI 架构

### 2.1 现状

现在每个电脑修士是一个约 100 行的函数：扫一遍周围，按固定顺序判断"撤退 → 躲技能 → 塔下后退 → 追进草丛 → 蹲草 → 打野 → 找目标 → 走位"，再按招式类型决定放不放。

它在一路上够用，因为所有人做的是同一件事。三路上不够，原因有三：

- 没有"我该在哪"的概念，位置是写死的那一条线。
- 没有全队视角。围剿血海残魂是唯一的集体行为，是硬塞进去的。
- 行为之间靠 if 的先后顺序决定优先级，每加一种行为都要重排。

### 2.2 三层结构

沿用 Dota 2 官方机器人脚本的分层：全队层给出意愿，传给每个机器人；机器人在自己的各个"模式"里选意愿最高的那个；模式内部再决定具体动作。

```
宗门调度（每队一个，1 秒一次）
  读：各路兵线、灵塔血量、敌人最后出现的位置、目标刷新时间、双方战力
  出：分路表、全队任务（推某路 / 守某塔 / 集合打目标 / 抓某路）及其紧迫度
        │ 任务 + 紧迫度
        ▼
修士决策（每人一个，每秒 4–5 次）
  每个模式算一个 0–1 的意愿，取最高的执行
  意愿 = 自己的考量 × 位置权重 + 全队任务的加成
        │ 当前模式
        ▼
动作（每秒 4–5 次，沿用现有代码）
  往哪走、打谁、放哪招、躲技能、补刀、蹲草
```

### 2.3 模式

每个模式两个函数：`意愿()` 返回 0–1，`执行()` 下命令。

| 模式 | 什么时候意愿高 |
|---|---|
| 对线 | 分到的路上有兵线，附近没有更急的事 |
| 发育 | 某路兵线没人收，或野区有营地，自己装备落后 |
| 巡山（打野） | 巡山位的常态；其他位置只在线上平稳时去 |
| 游走抓人 | 某路敌人压过中线、气血不满、己方在那路有控制 |
| 推塔 | 兵线进塔、敌人不在或人数占优 |
| 守塔 | 己方塔被打、自己离得不远 |
| 团战 | 附近双方各有两人以上交手，或全队任务是集合 |
| 打目标 | 全队任务，且目标附近己方战力占优 |
| 撤退 | 气血低、人数劣势、被塔锁定 |
| 归宗 | 气血灵力都低且安全，或灵石够买下一件 |
| 蹲草 | 敌人正朝这边来、自己没被看见 |
| 护送 | 护法位的常态：跟着养剑位 |

### 2.4 意愿怎么算（效用打分）

每个模式的意愿是几个"考量"的乘积，每个考量把一个原始数值通过一条曲线变成 0–1。例如"游走抓人"：

- 目标气血比例 → 越低越高
- 目标离己方塔的距离 → 越远越高
- 自己过去要多久 → 越久越低
- 那一路的己方有没有控制招式可用 → 有则高
- 自己的绝招好了没 → 好了则高
- 附近敌方战力 → 越高越低

这样做的好处是加一个考量不影响其他考量，加一个模式不用重排优先级；调参就是调曲线和权重，可以交给批量对打去试。

两条防抖规则：

- **惯性**：当前模式的意愿加 0.1–0.15，避免两个模式分数接近时来回跳。
- **最短停留**：换模式后至少保持 1–2 秒，撤退和守塔例外。

### 2.5 位置 = 权重表

不同位置用同一套模式，只是权重不同，放在配置里：

| 模式 | 镇关 | 中军 | 养剑 | 护法 | 巡山 |
|---|---|---|---|---|---|
| 对线 | 1.0 | 1.0 | 1.0 | 0.6 | 0.2 |
| 发育 | 0.9 | 1.0 | 1.3 | 0.2 | 1.0 |
| 巡山 | 0.3 | 0.4 | 0.3 | 0.1 | 1.4 |
| 游走抓人 | 0.6 | 1.0 | 0.3 | 1.0 | 1.3 |
| 团战 | 1.2 | 1.0 | 1.0 | 1.1 | 1.1 |
| 护送 | 0 | 0 | 0 | 1.5 | 0 |

数值是起点，要靠对打调。

位置还决定动作层的打法：

- **养剑**：保持最大射程，打一下退一步，站在己方近战身后。
- **镇关**：己方人到齐了才开团，开完贴住对方后排。
- **巡山**：从侧面或草里进场，优先找气血最低的脆皮，没有退路不进塔。
- **中军**：远程消耗，控制招式留给冲过来的人。
- **护法**：站在养剑身边，不抢补刀，治疗和罡气优先给气血最低的同门，先替人探草。

### 2.6 宗门调度看什么

它每秒更新一块"公告板"，所有修士都能读：

- **兵线状态**：每路的交战点在哪、哪边兵多、灵塔还剩多少血、有没有己方的人。
- **敌人最后出现的位置和时间**：只用己方看得见的信息，和玩家公平。超过几秒没看见的敌人算"消失"。
- **战力估计**：每个修士一个数，由境界、法器总价、气血比例、绝招是否就绪算出。
- **势力图**：把地图分成约 16 × 16 的粗格子，每格记"己方战力 − 敌方战力"，随距离衰减，消失的敌人按时间衰减。用于判断哪里安全、从哪条路撤、能不能进野区。

然后选一个**当前主要目标**。腾讯《王者荣耀》AI 的宏观策略论文就是这样分阶段的：阶段由"全队当前在争哪个主要资源"定义（某座塔、暴君、主宰、基地），再决定每个人该去地图的哪一块。论文里去掉宏观策略层的版本对完整版输了 75%，说明这一层比操作更值钱。

选目标的几条规则，按优先级：

1. **人数优势窗口**：敌方陨落或在远处露面的人数 ≥ 2，就去推最近的塔或打中立目标。这是 MOBA 里最要紧的一条宏观规则。
2. **塔快倒了**：己方塔危险且守得住就守，守不住就换（去推另一路）。
3. **目标刷新**：中立目标在、己方绝招多数就绪、战力占优，就集合。
4. **都不满足**：各回各位发育。

任务分配用贪心：每个任务对每个修士打分（距离、位置适配、状态），从最高分开始配，一人一个任务。

### 2.7 发育、团战、打野怎么平衡

这是你点名的问题。办法是三条约束加一组指标。

三条约束：

- **兵线不能白丢**：一波兵线进己方塔而没人收，是纯亏。只有团战或打目标的意愿超过一个阈值时才允许离开。
- **集合时留人**：集合推进时，另外两路最多各留一人带线，其余人集合。
- **打野有节拍**：巡山位按营地刷新时间走"清野 → 看一眼哪路能抓 → 抓或继续清"的循环，不会一直抓也不会一直刷。

一组指标，每轮批量对打后看：

| 指标 | 目标（起点） |
|---|---|
| 各位置每分钟灵石之比 | 养剑 1.0、中军 0.95、镇关 0.85、巡山 0.8、护法 0.5 |
| 每分钟团战次数 | 前 4 分钟接近 0，10 分钟后明显上升 |
| 第一座外塔倒下的时间 | 5–7 分钟 |
| 第一个中立目标被打掉的时间 | 刷新后 1 分钟内 |
| 兵线进塔没人收的次数 | 越少越好 |
| 对局时长 | 18–22 分钟 |
| 一边倒的局占比 | 15% 以下（现在一路是 14%–17%） |

节奏直接参考《王者荣耀》的通行分期，一局约 20 分钟：

| 时间 | 阶段 | 地图上发生什么 |
|---|---|---|
| 0–4 分 | 发育 | 各守各路，巡山位清野。外塔有减伤保护 |
| 4 分 | — | 外塔保护消失；开始出攻城弟子；两个中立目标首次出现 |
| 4–10 分 | 节奏 | 抓人、换塔、争中立目标 |
| 10 分 | — | 两个中立目标变强（效果更大，也更难打） |
| 10–18 分 | 团战 | 围绕中立目标和高地塔打团 |
| 18 分以后 | 决战 | 出现一个终局目标，打掉的一方三路弟子大幅强化，保证对局收得住 |

《王者荣耀》里对应的是 4 分钟防御塔护盾消失、10 分钟暴君和主宰进化、20 分钟风暴龙王。各篇攻略给的具体秒数不一致，这里只取结构。

### 2.8 信号和分路

开局前加一个**分路界面**：五个位置五个格子，按默认位置填好，你可以拖动调整，也可以点"自动"。

对局中的**信号轮盘**（按住 Alt 拖动，或触屏长按小地图）：

| 信号 | 电脑怎么响应 |
|---|---|
| 进攻这里 | 附近同门的"推塔 / 团战"意愿加成 8 秒 |
| 撤退 | 附近同门的"撤退"意愿加成 |
| 集合 | 全队"团战"意愿加成，带线的人除外 |
| 守这座塔 | 最近的两人"守塔"意愿加成 |
| 我来打这个营地 | 其他人不抢 |
| 请求支援 | 巡山位和最近的中军"游走"意愿加成 |

信号是加成不是命令：过去会送命的时候电脑会拒绝，并回一句"过不去"。

电脑也会主动发信号给你：敌人消失、准备打目标、请求支援、要抓你这一路了。现在"同门正在围剿血海残魂"已经是这个机制的雏形。

### 2.9 难度

现在三档难度主要靠敌方伤害倍率。三路之后改成主要靠"脑子"：

| | 简单 | 普通 | 困难 |
|---|---|---|---|
| 反应延迟 | 长 | 中 | 短 |
| 瞄准误差 | 大 | 中 | 小 |
| 响应全队任务 | 经常不理 | 多数响应 | 都响应 |
| 抓人 | 很少 | 有 | 频繁，会蹲草 |
| 人数优势时推进 | 不会 | 有时 | 会 |
| 伤害倍率 | 略低 | 持平 | 持平 |

## 3. 效率手段

### 3.1 为什么不用强化学习

OpenAI Five 和腾讯"绝悟"用的是强化学习或大规模模仿学习，需要海量对局和算力，产物是一个要随游戏下发的神经网络。我们是单个 HTML 文件，而且规则每周都在变，每变一次就要重训。

效用打分 + 规则是商业游戏里机器人的通行做法，可读、可调、改规则不用重来。

### 3.2 我们已有的优势：模拟很快

现在一局 16 分钟的对局约 2 秒模拟完。三路 5v5 估计 8–10 秒。这意味着：

- **新旧 AI 对打当回归测试**：每次改 AI，让新版打旧版 200 局，胜率低于 50% 就是改坏了。比看对称对打的指标更直接。
- **自动调参**：把权重表和曲线参数交给一个简单的搜索（爬山或进化策略），目标是"对上一版的胜率"加上 2.7 节的指标约束。一晚上能跑几万局。
- **固定随机种子**：现在的随机数没有种子，同一局无法重放。加上种子后，出问题的那一局可以原样重跑、单步看。

### 3.3 运行时开销

现在的实测：全部规则逻辑每帧 0.04 毫秒，渲染每帧 6.2 毫秒（最高画质，1440 × 810，这台 Mac mini）。逻辑不是瓶颈，但单位数翻三倍后有几处要改：

- **错开思考**：修士每秒想 4–5 次且相位错开（已有），宗门调度 1 秒一次，势力图 2 秒一次。每帧花在 AI 上的时间设一个上限。
- **事件触发重想**：挨打、收到信号、目标死亡时立刻重想，不等下一拍。
- **空间网格**：现在"找附近单位"和"单位互相推开"都是两两比较。40 个单位无所谓，100 个就是 6 倍。换成网格查询。
- **弟子合批渲染**：现在每个弟子一次绘制调用，再乘以阴影和环境光遮蔽两遍。约 60 个弟子时这是手机上最大的开销，要改成实例化绘制。
- **战力用估算**：打不打得过用 2.6 节的战力数相加比较，不做对局推演。

### 3.4 调试手段

- **决策面板**：点一个电脑修士，显示它每个模式的当前意愿和最高的三个考量。没有这个，调 AI 是瞎调。
- **小地图叠加**：势力图热度、每人当前的目的地、全队当前目标。
- **对局记录**：批量对打时把每次模式切换记下来，汇总成"各位置在各模式上花的时间占比"。

## 4. 连带要改的系统

| 系统 | 变化 |
|---|---|
| 经济 | 五人分三路的灵石；护法位不补刀，要有保底收入（附近同门补刀时分一份） |
| 修为 | 沿用附近均分；野区修为要够巡山位不落后 |
| 兵线 | 三路各自出兵；隔几波出一个攻城弟子 |
| 重聚时间 | 按境界递增，整体比现在略长（地图大了，死一次的代价应该更大） |

| 镜头 | 地图大了，需要屏幕边缘推镜头和空格回到自己 |
| 计分板、顶栏 | 5v5 排版 |
| 选人 | 加分路界面 |
| 新手引导 | 系统更多了，更需要 |
| 平衡 | 十二人数值要重新跑一遍对打 |

## 5. 分期

每期结束都能玩、能批量对打。

| 期 | 内容 | 验收 |
|---|---|---|
| 0 | 定第 0 节的事 | 已定 |
| 1 | 模式选择、两套数值表、方形地图、三路、九塔、三路兵线、5v5。电脑用现有 AI，各自分到一路。山脊和路点图放到这一期的后半 | 能打完一局；批量对打无报错 |
| 2 | AI 重构，用 Yuka（见 `库选型.md`）：公告板、兵线状态、模式 + 效用打分、位置权重表、分路界面。行为先不加新的 | 新 AI 对旧 AI 胜率 ≥ 50% |
| 3 | 战争迷雾和"最后出现位置"、巡山位、游走抓人、增益营地、信号轮盘 | 巡山位灵石占比达标；抓人成功率可统计 |
| 4 | 宗门调度：主要目标、人数优势窗口、集合与带线、第二个中立目标、团战站位 | 2.7 节指标进入目标区间 |
| 5 | 自动调参、难度三档、决策面板、十二人数值重调 | 胜率区间和一边倒占比不差于 v1.0.0 |
| 6 | 弟子合批渲染、手机适配、镜头、新手引导 | 手机真机可玩 |

每一期都不动一路模式；每期结束跑一遍一路的回归对打，确认它的数字没变。

---

## 6. 风险

- **工作量**：这是把游戏的地图、AI、经济、界面都动一遍，规模大约是 v1.0.0 的一半。
- **手机性能**：单位数约 2.5–3 倍。弟子合批渲染是必须项，不是优化项。
- **十二人偏少**：5v5 下阵容重复度高。允许镜像选人是权宜之计。
- **AI 调不好的表现**：全员抱团或全员各刷各的。2.7 节的三条约束和指标就是防这个，但要靠多轮对打才能收敛。
- **寻路**：山脊和路点图是新东西，卡墙、绕远是常见问题，第 1 期要专门测。
