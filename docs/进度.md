# 进度

给下一次接手的人（或者下一段对话里的我）看的：现在做到哪、怎么验证、接下来做什么。规矩、流程、代码地图和用语表在仓库根目录的 `CLAUDE.md`。

## 现状（V2 · v2.0.0）

- **两个模式**，标题界面选：一路 3v3、三路 5v5（王者式地图、战争迷雾）。
- **十八位修士**，两个模式共用招式机制。共用数值在 `src/config.js` 的 `HEROES`；各模式的修正在 `MODES.<模式>.heroTune`（乘在基础气血、攻击、术法和招式威力上）和 `MODES.<模式>.tune`（兵线、塔、野怪、时间点）。
- **三路的地图**：野区和线之间有实体山脊（一排巨石，留有入口），宗门的石栏和山门柱也是实体。寻路用 Yuka 的图搜索。一路没有山脊，但宗门的石栏和山门柱同样是实体，也走寻路图。
- **三路的电脑**：
  - 按位置组队（`SEATS`、`SEAT_FIT`）。
  - 空闲时做什么由 Yuka 的 `Think` 仲裁，位置权重在 `SEAT_BIAS`：巡山清野、抓人、支援；护法跟着养剑位、不抢补刀；中军在自己线稳的时候会游走。
  - 撤退、回应信号、全队集结（12 分钟后）、被压内塔回防仍是优先级判断。
  - 会在队内说话，包括"某路的某某不见了"。
- **信号**：集合 / 进攻 / 撤退（`Z` `X` `C` 或小地图下的按钮），外加一个**开团开关**（`V`）：开着时同门一直跟着玩家、打玩家打的目标，照样不送死；玩家陨落自动解除。
- **三路的目标**（三者各有自己的模型）：上河道血海残魂（全队伤害），下河道镇渊傀（己方弟子强化 55 秒），16 分钟后上河道换成渊主残念（弟子大幅强化 90 秒加全队伤害）。
- **打团按定位**：两个模式的电脑都按设计定位打（镇关先手、后排放风筝且不越过前排、巡山等先手后切脆皮、三路护法跟养剑位）。
- **一路从三路拿来的**（v1.2.0-alpha.4）：下方的镇渊傀（己方弟子强化 45 秒）、11 分钟后血海残魂的位置换成渊主残念（弟子大幅强化 75 秒加全队伤害）、实体宗门墙、"某某不见了" / "对面人多" 的喊话。电脑的其余部分还是原来的定时触发逻辑。
- **平衡**（v1.2.0-alpha.4，按新电脑重调）：只动了两张单人修正表，招式和共用数值没动。每个倍率在 0.90–1.15，同一个人同一项在两个模式里相差不超过 0.08。孙伯的气血、术法倍率几乎不起作用（他的治疗量主要来自招式基础值），所以多了一项招式威力 `pow`，目前只有他在用。结果见下面"最近一次平衡"。

## 招式去雷同（2026-11-14，v1.2.0-alpha.5）

作者指出射手招式雷同，随后要求把其他雷同严重的也区分开。改之前：林霜和苏紫烟四招类型完全一样；三个辅助各有"控制飞弹 + 群体罡气 + 范围治疗"；周远川和裴寂三招相同；六个人有加速类增益，三个人的大招是持续减速区。改之后每人至少有一招独有的：

| 修士 | 路子 | 换掉的 → 现在 |
|---|---|---|
| 沈焰 | 速射 | 机制没动（叠攻速、连珠、贯穿、滑步、全图定身）。v1.2.0-alpha.10 起形象改为**焰修**：两手各托一团心火，招式叫流火、焚天；为的是和林霜这个弓手区分开 |
| 林霜 | 高攻狙击 | 攻击高、出手慢、射程最远。被动改成"7 步外普攻 +18%"；霜羽改成不贯穿的重箭；冰心（加攻速）→ 冰棘（延时定身区）；大招 → 穿过弟子只打修士的斩杀箭 |
| 苏紫烟 | 技能型 | 被动改成"出招后下一次普攻强化并缩短听雪调息"；轻身符 → 回燕（飞到头折返，来回各打一次）；后撤 → 遁影（瞬移）；大招 → 横贯战场的巨大剑气；出装带调息 |
| 吴镇岳 | 范围炮台 | 攻击更高、出手更慢；后撤 → 镇岳（架势：射程和攻击提高、身法降低） |
| 周远川 | 嘲讽坦克 | 冲撞 → 踏星（加速并减伤的冲阵） |
| 裴寂 | 拘拿先手 | 嘲讽 → 天刑令（周身减速并给自己罡气）；冲撞 → 执法（瞬到目标身前定身）；大招 → 镇渊（把周围的人全部拘到身前） |
| 血屠子 | 吸血坦克 | 血锁从"拽人"改成"把自己拽过去并定身" |
| 陆青崖 | 剑修斗士 | 大招从点人瞬移 → 直线穿出一大段的斩杀冲刺 |
| 柳红衣 | 刺客 | 血雾从战斗增益 → 隐身（附带攻速、吸血、减伤） |
| 闻人遥 | 抓单刺客 | 没动（钩子留给他） |
| 沈渊 | 雷法 | 闪现 → 雷行（带伤害、会留雷印的冲刺） |
| 孙伯 | 治疗 | 群体罡气 → 行气丹（给附近同门加身法和攻速）；治疗更吃术法强度 |
| 言照雪 | 护盾与遮蔽 | 治疗 → 藏形幕（附近同门隐身、减伤，附带一小口回复） |
| 陆玄机 | 削弱与控制 | 群体罡气 → 卜凶（区域易伤） |

韩不语、老铁、周易、寒漪没动。试过又撤掉的：闻人遥的钩子改成"拽自己"，电脑在一路会把自己送进人堆，胜率掉到 21%。

同一批还改了：
- **一路取消归宗**（作者要求）：万宝阁只在出山前和陨落时开，`MODES.single.noRecall`。电脑残血时走回护山大阵。取消后一边倒的局从 17% 降到 2%。
- **塔的基础伤害** 150 → 185。
- **升级节奏**：一路 4 级从约 2 分钟推到 2 分半；三路有自己的曲线（`tune.xpNeed`），约 3 分钟到 4 级、8 分钟到 8 级、16 分钟满级（原来 2 / 6 / 12 分钟）。
- **三路时长**：塔和阵眼加厚、集结和渊主残念的时间后移，平均从 18.2 分钟到 19.6–19.8 分钟。

## 最近一次平衡（2026-11-14，v1.2.0-alpha.5）

招式改完后重新调了六轮（每轮一路 432 局、三路 204 局）。大的失衡先改共用的招式数值，剩下的才用两张单人修正表，仍守住"每个倍率 0.90–1.15、同一项两个模式相差不超过 0.08"。

| | 最后一轮 | 说明 |
|---|---|---|
| 一路 | 432 局，42%–62%，平均 14.4 分钟，一边倒 2%，1 局打满 25 分钟 | 取消归宗之后跑的；十八人里十三人在 46%–56% |
| 三路 | 204 局，44%–60%，平均 19.7 分钟，无未完成 | 十八人里十五人在 44%–53% |

## 感悟、针对、战绩（v1.2.0-alpha.13）

- **感悟**：**只有一次，在 9 级（元婴初期）**，二选一，只改绝招（作者 2026-11-14 的最终决定；之前试过 8 级和 12 级各一次、也试过改普通招式，都撤了）。数据在 `config.js` 的 `INSIGHT`，每人两条。只改这一招的数值（范围、调息、时长、伤害等），在 `eff()` 里套上；电脑随机选。玩家在招式栏上方点选，或按 `5` / `6`；不选就一直挂着。选择框只在安静的时候出现：脱战 3.5 秒以上、16 步内没有看得见的敌方修士（陨落时也会出现）；打起来会收回去，安静了再出来。
- **电脑针对玩家**：玩家连镇三人后，对面选目标时优先打他，并喊一声"先杀某某"；玩家反复钻的那片草丛（进过三次以上），对面蹲草时优先去那里。
- **战绩与成就**：存在浏览器本地（`localStorage` 的 `frostember.rec`），每位修士的场次、胜场、镇压、最高连镇，加十一个成就；标题页人物说明下面一行显示，结算时提示新得的成就。换设备或清缓存就没了。
- **陨落倒计时**：之前一直不显示，是显隐判断写反了（`===` 应为 `!==`），现在屏幕中间有大号读秒。
- 感悟对平衡的影响没有量过（双方电脑都随机选，理论上对称）。

## 测试与整理（v1.2.0-alpha.14）

- **性能**：三路一帧完整渲染 5.6 毫秒（1440×810，高画质），其中游戏逻辑 0.16 毫秒；模拟一秒对局耗 3.6 毫秒。瓶颈在渲染，逻辑没有可优化的必要，没动。
- **清理**：删掉了没有招式再用的出手特效（gale、rocketjump、rain）、弹道分支（shellshot）、三个图标和一条音效映射。
- **平衡**（一路 432 局、三路 204 局，感悟上线后第一次量）：一路 37%–65%，三路 45%–61%。据此下调了一路的苏紫烟、沈渊、吴镇岳，上调了一路的林霜、裴寂，三路下调了陆青崖、韩不语；苏紫烟的招式基础伤害略降。改完没有再跑大样本。
- 新增 `prof.mjs`、`gapcheck.mjs`。

## 电脑怎么选感悟、怎么说话（v1.2.0-alpha.15）

- **选感悟**：每条感悟带一个用途标签（范围、控制、成招快、伤害、斩杀、调息、射程、持续、治疗、照应）。电脑看对面阵容打分（`pickInsight`）：近战多选范围和持续，身法灵活的多选控制和成招快，皮厚的多选伤害，脆的多选斩杀，远程多选射程，有辅助回血选调息。带一点随机，免得每局一样。
- **告诉玩家**：只有同门会在队内频道报告自己选了什么、为什么选（"对面爱扎堆"之类），带一行小字说明效果。对面的感悟不说（作者的决定）。
- **说话看性格**：`barks.js` 的 `TONE` 给每人一种口气（沉默、判词、粗口、冷、火、长者、推演、傲、温和、血宴、暗影、疯、端正等十四种），`VOICE` 按"口气 × 场合"取词，没有就用通用的。场合包括撤退、镇压、陨落、推塔、丢塔、拿目标、回应三种信号、来不了的两种原因、开局、开团、感悟、针对。
- **对面也说话**：用同一套口气，红色显示，频率低得多（全队 22 秒、每人 60 秒，再打五五折）。对面**只说冲着你们来的话**（`eKill` / `eDie` / `eAhead` / `eBehind` / `eStart` / 针对），不说撤退、推塔、感悟这类给自己人的报告；`chat()` 里的 `FOE_SAYS` 是白名单。同门的报告类发言间隔是每人 4 秒、全队 1.2 秒，感悟那一条在屏幕上留 11 秒。针对的话是"此子不可留""全宗门听令，镇杀某某"一类，各人说法不同。
- 没量过新的感悟选择对平衡的影响；电脑选得"对不对"也只看了逻辑，没有对照实验。

## 雷劫（v1.2.0-alpha.17）

两次，大小不同（`TRIB` 在 `game.js`）：

| | 准备 | 落雷 | 罡气 = 落雷的总伤害 |
|---|---|---|---|
| 结丹（5 级） | 10 秒，可移动 | 5 波，5 秒，期间定身 | 最大气血的一半 |
| 成婴（9 级） | 10 秒，可移动 | 9 波，9 秒，期间定身 | 最大气血的全部 |

- 准备的十秒天色变暗、镜头拉远，头顶有雷云，渡劫者可以走动挑地方；十秒一到，原地定身，开始落雷。
- 每一波，渡劫者一屏之内（24 步）的每一位修士脚下各出一个收缩的金环，0.9 秒后劈下；敌、友、渡劫者自己都在内。站在一起，同一波也只会挨一下。走出金环就躲开了，渡劫者定着躲不了。
- 每一波的伤害 = 罡气量 ÷ 波数，所以全部挨下也正好被罡气吃掉，独自渡劫劈不死。
- 附近 34 步内镜头拉远、天色压暗、饱和度降低（`G.tribK` → `main.js`，渲染里多了一个 `uDusk`）。
- 电脑会走出金环。

## 法宝（v1.2.0-alpha.19）

法宝从六件加到八件，凡器、灵器不变：

## 电脑出装（v1.2.0-alpha.20）

- **第一件法宝**是每人固定的核心（`HEROES[id].build[0]`），由 `builds.mjs` 的演算决定（见下）。
- **之后每一件临场挑**（`game.js` 的 `itemScore` / `nextPiece`）：按法宝给这个人的进攻（吃哪项属性就算哪项）、防御、身法打分，按位置加权（镇关重防、养剑重攻、巡山重身法、护法重调息）；局势再修正：落后（镇压数落后 4 个以上或自己死得多）防御 ×1.45，领先进攻 ×1.2；对面六成以上是物理伤害时镇关尺加分；近战面对六成以上远程时身法更值钱。`build` 里第二、三件仍有少量加分，保留设计意图。一旦开始攒某件就攒完再换。
- **研究出装**：`HERO=<id> BUILD='{"<id>":["<法宝>"]}' node batch.mjs …` 让某人强制先出某件、并且每局都跟踪他；`node builds.mjs "runs/bd_*.jsonl"` 汇总每人每种核心的胜率。批量结果里每人多了 `items`（最后持有的法宝）。

## 音效重做（v1.2.0-alpha.20）

- 作者说原来的音效"像锅碗瓢盆"。原因是几乎每一下打击都叠了一圈金属泛音。现在用 **Tone.js** 设计音色（`src/sfx.js`）：打击是膜鼓的"咚"加噪声的"啪"、带一点饱和，剑才有共鸣的"嗡"，冰是细碎的晶粒，雷是爆裂加低频滚动，弓弦是拨弦。
- 开局时离线渲染一次（每种三个变体，常用的先渲染），约 4 秒全部就绪，期间先用旧的即时合成顶上。之后每次播放只是一个缓冲区，仍走原来的 3D 定位和混响。
- 拨弦没有用 Tone 的 PluckSynth：它依赖 AudioWorklet，从 blob 地址加载，在本地文件和沙箱页面里会被拒。改成自己算的 Karplus–Strong。
- 开发时 `npm run dev` 会先跑 `vendor.mjs` 把 Tone.js 打成 `vendor/tone.js` 给 import map 用；正式打包直接从 node_modules 打进去，页面从约 1.1 MB 涨到约 1.36 MB。
- 配乐和环境声没改。没有人耳听过新音效，只量了音量。

## 出装演算与法宝平衡（v1.2.0-alpha.21）

- 第一轮演算（每人 × 每件可选首件法宝 × 40 局一路）：12 个物理修士里有 9 个首出镇关尺最好，连射手也是；遁影镜、困龙索、照魂镜几乎人人垫底。说明是法宝本身不平衡。

- **蓝方小优势（未解决）**：对称对局里霜方（蓝方）一直多赢 3–4 个百分点。用旧版本对照（各 432 局一路，标准误约 ±2.4）：alpha.14 52.3%、alpha.16 54.2%、alpha.17 53.5%、alpha.18 58.3%、当前 54–56%。不是某一版突然引入的。每个修士在两边出现的次数一样，所以对个人胜率影响不大。已排除：对面集火玩家、对面蹲玩家常去的草丛——这两条在机器对打（`G.autoPlay`）时现在关掉了，只对真人生效，关掉后仍是 54%。下一步可查：地图是否完全对称（一路的镇渊傀营地在 x=1.5，不在正中）、玩家（总在霜方）走的代码路径。

## 阴影闪烁（v1.2.0-alpha.21）

作者反映走路时光影一闪一闪。原因：太阳的阴影框跟着镜头按地面 2 步一格移动，这既不是整数个阴影贴图像素，也不沿光源自己的坐标轴，所以每走一两步，画面里所有阴影边缘就挪动零点几个像素。现在按光源坐标系、以整像素为单位移动（`W.focusLight`）。验证：镜头移动时，地面上一个固定点在阴影贴图里的亚像素位置保持不变。

## 配乐乐器与情绪、沈渊（v1.2.0-alpha.22）

- 配乐的谱子（五声音阶、乐句、和弦、打斗时的鼓）不变，乐器换成 Tone.js 渲染的采样：古琴（暗而长的拨弦，起音后有一点"吟"）、箫（气声、渐起的颤音）、大战鼓和小鼓。开局先渲染乐器（几十毫秒），再渲染音效。

- 沈渊：雷印引爆 6% → 4.5% 最大气血，引爆后 3.2 → 3.8 秒内不再留印；修正表一路术法 0.97、三路 1.03。

## 每人的兵器声、大招、雷劫、环境声（v1.2.0-alpha.23）

- 作者说音效"还是有点卡通"，要每人的兵器和法术声音多样。
- **每人两种声音**（`sfx.js` 的 `w_<id>` / `h_<id>`）：出手（挥、射、放）和命中。例：韩不语重尺是低沉的破风和钝响，周远川盾击是闷响加木铁的箱体声，裴寂刑杖是细杖破风和木头的脆裂，血屠子血爪是撕裂和湿响，沈焰是火苗一窜和噼啪，林霜是低沉的弓弦和带冰碴的箭中，吴镇岳弩机是扳机、弦响和木托，周易是星光的嘶声，寒漪是冰屑，沈渊是电弧爆响，孙伯是符纸一甩，言照雪是闷闷的衣幕，陆玄机是铜钱的鸣响。
- **去卡通**：打击用的膜鼓不再大幅降调（那是"嘣"的来源）；蓄力、护盾、施法、回城、陨落不再用正弦滑音，改成噪声质感加少量低调制 FM。
- **大招**：任何人放大招都有一下"吸气—重击—低钟"。
- **雷劫**：准备开始时远处一声闷雷；之后每一波只响一声雷，一波比一波重，最后一波加炸裂和钟声。
- **环境声**（作者要的）：五种循环底声按镜头位置混合——蓝方雪山的风啸（带口哨声和冰晶）、离路远的林间树叶声、河边的流水、红方血阵和血海残魂坑附近的稠血冒泡加低鸣、红方焦土的余烬噼啪。
- 渲染顺序：乐器 → 音效（常用、每人兵器优先）→ 环境声。都还没有人耳听过。
- 沈渊：雷印引爆对修士的比例改成按模式的数值 `tune.markHp`（一路 3%、三路 5%），和 `selfPullStun` 一样是数值例外，不是机制改动。
- 沈渊之后的专项测试（他每局都在，192 局一路、96 局三路）：削引爆后一路仍 70%；真正的原因是首件星络护腕的调息让他在窄路里连放刑雷。改首件为命盘后一路 58%（其中约 4 个点是蓝方优势）、三路 45%，三路术法倍率提到 1.05。

## 本地 Chrome 应用与性能（v1.2.0-alpha.24）

- **`npm run app`**（= `node build.mjs && node app.mjs`）生成 `dist/霜烬之争.app`：自带一份游戏文件，双击用 Chrome 的应用模式打开（没有标签页和地址栏），用自己的配置目录 `~/Library/Application Support/Frostember`（设置和战绩与平时浏览分开），允许声音自动播放、开 GPU 加速。图标是程序画的"霜烬"两字。需要本机装有 Google Chrome，没装会弹提示。
- **性能测量**（`frameprof.mjs`，1440×810 高画质）：GPU 每帧约 5.6 毫秒，游戏逻辑 0.13 毫秒；CPU 剖析里排第一的上传矩阵其实是在等 GPU。播放中没有重新编译着色器（始终 43 个）。全部音效、乐器、环境声约 1 秒渲染完，期间没有超过 50 毫秒的长任务。结论：桌面上没有值得冒险改画面的瓶颈。
- **做了的**（不改变画面和声音）：标题页上第一次点击就开始渲染声音（以前要等开局）；发布版关掉 three.js 每次编译着色器的错误检查（开发服务器上保留）；主循环拆出 `tick()`，测试可以 `__moba.frame(dt)` 一帧一帧跑。
- **考虑过没做的**：把地面着色器里逐像素循环的营地、草丛烘成贴图（边缘会变软，画面会变）；阴影隔帧更新（影子会拖）；音频降采样（音质会变）。

## 手机音频（v1.2.0-alpha.25）

作者报"手机上没声音"，后来确认是手机开了静音，原版本在他手机上本来就正常。这一版保留的改动：
- Tone 在任何渲染之前接到游戏自己的音频上下文（`attach(ctx)`），不会再另开一个实时 AudioContext。
- iOS 16.4+ 设为播放模式（`navigator.audioSession.type = 'playback'`）：**静音开关打开时也会出声**。如果作者想让游戏跟随静音开关，删掉 `audio.js` 里这一行即可。
- 每次点击都会尝试唤醒被挂起或打断的音频。
- 网址加 `?sound=simple` 只用即时合成的简单音效。
- `renderGroups` 支持把多个音效合在一次离线渲染里（`maxSec`），目前电脑和手机都用一个音效一次（实测最快）。曾为手机改成一种变体、分批、不要环境声，作者确认原版本没问题后已恢复。

## v2.0.1：弓箭声

作者说普通弓箭的声音难听、吵，像弹吉他。原因：弓弦用的拨弦会响 0.5–0.7 秒，就是一个吉他音。现在弓（通用 `bow`、林霜 `w_linshuang`）和弩（`xbow`、吴镇岳 `w_gunner`）都改成短促的"弦一弹、弓臂一震、箭一嘶"，拨弦只留 0.07–0.13 秒，音量也调低。`pluck()` 多了时长和衰减两个参数。

## v2.0.2：按兵器和法术类型的写实声音、大场面更突出

- **普攻要短**（作者要求）：通用挥砍和打击的尾音缩短，普攻、弟子打击在混音里压低（出手 0.32、命中 0.38）。
- **"轰"不再滥用**：以前几乎所有范围招式落地都放大爆炸声，大场面就不突出了。新增三种中等声音：`blast`（符箓、炮弹炸开：雷火符、万符齐发每一轮、雷音符），`zapcrack`（一道落雷：刑雷、天刑每一击），`slam`（跳砸落地：镇关、镇渊等，原来是爆炸）。`boom` 只留给星落和灵塔、阵眼被毁。
- **修了静音和错配**：四处调用了不存在的声音名（没有声音）；嘲讽在吹战号；清魂阵放的是升级音效；静时阵 / 逆运落地吹战号；冲刺撞人用的是弟子的小敲击声。
- **大场面**：大招、真正的爆炸、镇压、陨落、战号，以及最重的雷劫雷声，音量更大，并且约一秒内把其他音效压到四成、配乐压到一半再慢慢回来（`audio.js` 的 `BIG` 和 `small` / `mduck` 两个总线）。

## v2.0.3：逐个推演全部声音后的修正

写全部声音报告（Claude Docs：「霜烬之争 · 全部声音报告」，https://claude.ai/artifact/TFpBn1jXKafUxdCuZ43WQb ）时逐个对照"该像什么"，又改了：刑雷、天刑、雷音符的元素层从 1.8 秒的雷滚改成短促的电声（雷滚只留给雷劫，原来刑雷落地那一下会压低全场）；星引出手从电声改成施法声，缚灵符改成破风；回风刀从魔法声改成重挥；吴镇岳每第四箭从大爆炸改成符炸；土元素层音量降到 0.45；大爆炸 0.72 不再爆音。

## v2.0.4：按人物和招式本身设计声音

- **签名声**（`sfx.js` 的 `sig_<id>`，18 个）：从人物出发的短动机，轻轻叠在他每一招下面（`SIG_GAIN` 0.5）。例：韩不语是被压住的剑意嗡鸣，裴寂是惊堂木两下，血屠子是慢而稠的脉搏，周易是两个星音，陆玄机是摇钱、签落地。
- **每招用什么声音**（`src/skillsound.js` 的 `SKSND`）：按这一招实际是什么来定（出手 `cast`、落地 `land`、弹道命中 `hit`），有条目时 vfx.js 里按特效来的声音不再响（`quiet` 标记）。修掉的错配：裴寂的执法有血声、言照雪的蔽天和静时阵 / 逆运是冰声、陆玄机的钱是周易的星声、血屠子的化血是普通玻璃罡气、苏紫烟的遁影镜是星声。
- 详细的逐人推理在全部声音报告里。新增招式时要在 `SKSND` 里给它一条，否则用特效对应的默认声音。

## v2.0.5：血屠子更耐打，血海跟着他

作者觉得血屠子弱，要提高生存。改动：化血罡气 10% → 15% 最大气血、调息 12 → 10 秒；血爪吸血 55% → 70%；血海吸血 70% → 90%；血炼回复 3.5% / 14% → 4.5% / 16%；**血海跟着他走**（作者要求，`follow: true`，`updateZones` 里每帧把阵和地面圈挪到施法者身上）；电脑操作他时三成血以下就撤（原来约两成七）。
专项测试（他每局都在，一路 192 局、三路 96 局）：每局陨落 一路 4.5 → 4.0、三路 8.5 → 7.8；胜率 一路 59%（其中约 4 个点是蓝方优势）、三路 55%。只加吸血时陨落几乎没降，主要是血海跟随和早撤起作用。

## 踩过的坑

- macOS 文件系统不分大小写，`runs/A0.jsonl` 会覆盖 `runs/a0.jsonl`。
- `rm` 带通配符会被拦，测试产物靠 `.gitignore` 挡在仓库外，不必清。
- 地面着色器是按当前模式生成的字符串；凡是写死的地图尺寸（80、48、64、75）都要换成 `MAP` / `POS`。上一次漏了"界外压暗"，把三路的山门涂黑了。
- 一路的车道是公式（s 就是 x），三路的是折线路径。改电脑逻辑时用 `L.at / L.proj / sOf`，不要直接用世界坐标的 x。
- 无头浏览器里 `requestAnimationFrame` 被限速，截图前用 `__moba.sim(秒)` 推进，动画类效果（慢动作、镜头推近）测不到。
