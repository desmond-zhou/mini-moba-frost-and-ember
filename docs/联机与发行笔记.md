## V3 为什么用帧同步

研究文档原本推荐服务器权威。动手时改成帧同步（每台机器跑整局，服务器只转发操作），理由：

- 画面、声音、界面一行不用重写，单机和联机走同一套代码；
- 服务器只是一个约 200 行的转发器，几乎不占资源。

代价有两个：

- 必须保证每台机器算得完全一样：靠 `src/dmath.js`，并用 `dettest.mjs` 验证；
- 迷雾挡不住改客户端的人：朋友之间玩可以接受，公开运营时再换服务器权威。

## 服务器怎么开

- **作者的要求：服务器不自动启动、不常驻。** 双击 `霜烬之争服务器.app` 才启动（`npm run app` 生成，Release 里是 `Frostember-server-mac.zip`），终端窗口里显示地址，关窗口就停。不要加 launchd 之类的开机自启。
- 作者的设备都在 Tailscale 里。服务器开着时，用 `http://des-mac-mini:8790/` 或窗口里显示的 Tailscale 地址打开。
- 对公网开放（`tailscale funnel`、Cloudflare 临时隧道）要作者同意，还没有做。

## 让房主自己跑服务器（不要专用服务器）

可行，而且帧同步正好适合：

- 服务器只转发操作，流量很小；
- 每台机器都有整局状态，房主掉线可以换一个人接着发令（房主迁移）。

难点不在算力，在连接：

1. **房主双击服务器应用（已经有）。** 同一个局域网或同一个 Tailscale 里，现在就能玩。不在的话，要靠穿透（Cloudflare 临时隧道或 `tailscale funnel`）给一个公网链接。
2. **房主直接在浏览器里开房**（WebRTC 点对点，比如 Trystero 这个库，借公共服务牵线）。好处是谁都不用装东西。坏处：
   - 约一到两成的网络组合打不通，要靠中转服务器，而中转服务器要花钱；
   - 公共牵线服务在大陆可能被墙，跨境直连也不稳；
   - iPhone 一切到别的应用，页面就暂停，所以必须配上房主迁移。

建议的顺序：

- 先在服务器应用里加「生成公网链接」，只有勾选才开、关窗口就断。大约半天，开放公网需要作者同意。
- 以后再做浏览器开房 + 房主迁移，连不通时退回服务器应用。大约 2–3 天。

## 版号

- **是什么：** 国家新闻出版署发的「网络游戏出版物号」。在大陆面向公众上线运营网络游戏，按规定要先拿到，收费的游戏尤其如此。
- **怎么拿：** 个人一般申请不了，要由有资质的出版单位代为申报。需要软著、公司主体、实名认证和防沉迷系统；主管部门会审内容（暴力血腥、赌博、迷信、价值观、未成年人）。审批按月分批公布，周期几个月到一年以上。
- **对本游戏：**
  - 朋友之间私下玩、不收费、不公开推广：碰不到版号问题；
  - 面向海外玩家：不需要版号；
  - 在大陆正式发行并有收入：绕不开版号，到时「血屠子」一类的名字和画面可能要为过审调整，还要加实名认证和防沉迷。
- **反面例子：** 厦门有公开案例，未经审批的游戏放在租来的云服务器上公开运营并开充值，被处罚。

## ICP

只看服务器放在哪里，不看玩家在哪里。

- **服务器在大陆以外**（加拿大、香港、日本等）：不需要 ICP。
- **服务器在大陆、用域名对公众开放网页：** 要备案。不收费是「非经营性备案」，免费，找云服务商代办，一两周到一个月；收费要办「ICP 经营许可证」，门槛高得多。没备案的域名会被服务商直接拦掉。
- **服务器在大陆、只给自己和几个朋友用的网络服务、不开网站：** 一般不需要。
  - 但我们的服务器也会把游戏网页发给浏览器，所以不要给它绑域名，用 IP 加端口或 Tailscale 访问。
  - 最省心的是全走 Tailscale：服务器不对公网开任何端口。
- **大陆家里的宽带：** 本身做不了备案，对外开服务也违反家宽的使用条款，而且常常没有公网 IP。只用 Tailscale 让自己的设备互连没有这个问题。
- **跨境：** 海外朋友连大陆服务器延迟大、不稳定。想照顾国内玩家的延迟，常见做法是把服务器放在香港、东京或新加坡，不用备案。
